# Security policy

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/espm1000/opentripsplit/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You'll get an acknowledgement within a week. Once a fix is released, the advisory is published with credit to you (unless you'd rather stay anonymous).

## Supported versions

Only the latest release gets security fixes.

## Scope

In scope: this repository's code and the default Docker image.
Out of scope: how a particular instance is deployed (TLS, reverse proxy, host security), and issues in GitHub or Discord themselves.
